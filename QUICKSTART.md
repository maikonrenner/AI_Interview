# 🚀 Interview-IA - Quick Start Guide

Get up and running in 5 minutes!

## ⚡ Installation (2 minutes)

```bash
# 1. Navigate to directory
cd AI_Interview

# 2. Install dependencies
npm install

# 3. Start the app
npm run dev
```

## 🔑 API Keys Setup (2 minutes)

### Get OpenAI Key:
1. Go to https://platform.openai.com/api-keys
2. Click "Create new secret key"
3. Copy the key (starts with `sk-...`)

### Get Deepgram Key:
1. Go to https://console.deepgram.com/signup
2. Sign up (get $200 free credits!)
3. Copy your API key

### Configure in Interview-IA:
1. Launch Interview-IA
2. Click `⋮` (three dots) → Settings
3. Paste OpenAI key
4. Paste Deepgram key
5. Click "Save Settings"

## ✨ Start Using (1 minute)

### Ask a Question:
```
Press: Cmd+Shift+Q (or Ctrl+Shift+Q on Windows)
Type: "How do I reverse a linked list?"
Press: Enter
```

### Live Coding Mode:
```
1. Open LeetCode problem in browser
2. Press: Cmd+Shift+L (activate Live Coding)
3. Press: Cmd+Shift+C (capture screen)
4. Press: Cmd+Shift+S (analyze)
5. Get instant solution with explanation!
```

### Voice Input:
```
Press: Cmd+Shift+V
Speak: "Explain binary search algorithm"
Wait for transcription → Auto-submitted
```

## 🎯 Essential Shortcuts

## 💡 Pro Tips

### Tip 1: Cache Saves Money
- Interview-IA caches frequent questions
- Second time asking = instant + free!
- Cache auto-clears after 100 entries

### Tip 2: Use GPT-4o-mini
- 10x cheaper than GPT-4o
- Still very powerful
- Perfect for most questions
- **Cost**: ~$0.30 for 100 questions

### Tip 3: Real-time Mode for Contests
```
1. Open coding competition site
2. Activate Live Coding (Cmd+Shift+L)
3. Enable Real-time (Cmd+Shift+R)
4. Interview-IA captures screen every 8 seconds
5. Get hints automatically!
```

### Tip 4: Auto-Hide for Interviews
- Interview-IA automatically hides when you share screen
- Use it BEFORE your turn to share
- Get help discretely
- No one will see it!

## 🔧 Common Issues

### "AI Service not initialized"
**Fix**: Enter OpenAI API key in Settings

### "Transcription Service not initialized"
**Fix**: Enter Deepgram API key in Settings

### Voice not working
**Fix**: Grant microphone permissions
- macOS: System Preferences → Security → Microphone
- Windows: Settings → Privacy → Microphone

### OCR gibberish
**Fix**: Capture specific window, use high contrast theme
